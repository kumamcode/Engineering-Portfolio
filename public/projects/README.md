# Project Images Directory

Place your project images here, organized by project.

## Structure

```
public/projects/
  project-name-1/
    image1.jpg
    image2.jpg
    image3.jpg
  project-name-2/
    image1.jpg
    image2.jpg
```

## Image Recommendations

- **Format**: JPG, PNG, or WebP
- **Thumbnail Size**: 800x600px (will be auto-optimized)
- **Full Size**: Max 1920x1080px
- **File Names**: Use descriptive names (e.g., `assembly-view.jpg`, `detail-closeup.jpg`)

Next.js will automatically optimize these images for fast loading.
